# Fast and Unsupervised Non-Local Feature Learning for Direct Volume Rendering of 3D Medical Images

This repository hosts the project page for the IROS 2021 paper.

Xinmei Fu, Zhenzhou Shao, Ying Qu, Yong Guan, Yibo Zou, Zhiping Shi, and Jindong Tan.

Published in the **2021 IEEE/RSJ International Conference on Intelligent Robots and Systems (IROS)**.

Project page: <https://xinmeifu.github.io/fast-unsupervised-non-local-dvr-medical-images/>

Paper DOI: <https://doi.org/10.1109/IROS51168.2021.9636042>

## Overview

The page summarizes the paper's unsupervised non-local feature learning approach for medical direct volume rendering. It includes the method overview, selected experimental figures, research positioning, and a copy-ready BibTeX entry.

## Repository Contents

- `index.html`: static project page.
- `styles.css`: responsive page styling.
- `assets/real-results/`: method and result figures used by the page.
